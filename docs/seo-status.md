## Daily completion definition

A day is marked complete only when its log records:

- Search Console checked or the access failure documented.
- Keyword/SERP evidence checked and unverified metrics labeled honestly.
- A meaningful page, optimization, or audit completed.
- Internal links and technical SEO verified.
- Lint/build/deployment/public verification completed when code changed.
- Index request status recorded when applicable.
- Scheduled external article or exposure published, or a concrete reason for skipping it recorded.
